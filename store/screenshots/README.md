# 스크린샷

Play Console > 스토어 등록정보 > **휴대전화 스크린샷**에 올릴 이미지를 여기 넣는다.

| 항목 | 요구사항 |
| --- | --- |
| 장수 | 최소 2장, 최대 8장 |
| 형식 | PNG 또는 JPEG |
| 비율 | 16:9 또는 9:16 (세로 고정 게임이므로 **9:16**) |
| 크기 | 한 변 320~3840px. 1080×1920이면 넉넉하다 |

## 무엇을 찍을까

4장이면 충분하다. 게임이 뭔지 한눈에 보이는 순서로.

1. **플레이 중** — 동전·지폐가 쌓여 있고 점수가 보이는 화면 (제일 중요)
2. **합치는 순간** — 콤보 표시가 떠 있으면 더 좋다
3. **메뉴 화면** — '돈 불리는 순서' 체인이 보여서 규칙이 바로 이해된다
4. **랭킹** — 이번주/이번달/명예의전당 탭

## 찍는 법

실기기가 가장 정확하다. 폰에 앱을 깔고 **전원 + 음량↓**를 함께 누르면 찍힌다.

```bash
cd android && ./gradlew installRelease
```

PC 브라우저로 찍어도 규격만 맞으면 된다. 개발자 도구(F12) > 기기 툴바에서
해상도를 1080×1920으로 맞추고 찍는다.

```bash
npx http-server -p 5317 -c-1 .
```

> 스크린샷에 실제 게임 화면이 아닌 것(합성 이미지, 없는 기능)을 넣으면 정책 위반이다.
> 글자나 테두리를 덧붙이는 것 자체는 괜찮지만, 화면 내용은 실제와 같아야 한다.
