# 게임물관리위원회 등급분류 신청 자료

| 파일 | 용도 |
|---|---|
| `게임물개요.txt` | 신청 화면의 **게임물 개요** 입력란(1000자 이내)에 붙여넣는 내용 |
| `게임물내용설명.txt` | 첨부하는 게임물내용설명서 |
| `게임실행방법.txt` | 심사관용 실행 안내. 첨부 파일로 올리고, 제출용 zip 안에도 `실행방법.txt`로 넣습니다 |

## ⚠️ 내용수정신고가 필요한 상태 (2026-08-22)

등급분류(제 `SC-OM-260819-005` 호, 전체이용가)를 받은 뒤 게임 내용이 바뀌어
**세 문서를 모두 개정했습니다.** 등급분류를 받은 게임물의 내용을 수정하면
24시간 이내에 게임물관리위원회에 **내용수정신고**를 해야 하고, 위원회가 신고를
받은 날부터 7일 이내에 등급 재분류 대상인지 통보합니다.

바뀐 내용은 `게임물내용설명.txt`의 **10항 「최초 등급분류 이후 변경 사항」**에
정리해 두었습니다.

1. **유료 상품 「광고 제거」 추가** — 최초 신청서에는 "인앱결제 기능이 전혀
   없습니다"라고 기재했으나 유료 상품이 생겼습니다. 가장 중요한 변경입니다.
2. **플랫폼 참여 보상 이벤트** — 하루 1분 플레이 시 토스포인트 5원 확정 지급.
   최초 신청서의 "현금성 보상은 일절 없습니다"와 달라졌습니다.
3. 편의 기능 사용 횟수 3회 → 5회
4. 화폐 그래픽을 단순 도형에서 실제 원화를 본뜬 일러스트로 교체

재분류 대상 기준(게임머니 충전·이체·사용 방식 수정, 사행성·과몰입 유발 진행방식
수정 등)에 비추면 광고 제거 상품은 게임 내 재화를 충전하지 않고 사용 횟수 제한도
그대로여서 **재분류까지 가지 않을 가능성이 높다고 보지만, 판단은 위원회 몫입니다.**
신고 여부와 절차는 게임물관리위원회에 확인하시기 바랍니다.

## 제출용 zip 만들기

심사관이 압축을 풀자마자 실행 안내를 보도록, 게임 파일과 같은 위치에
`실행방법.txt`를 넣어 압축합니다.

```bash
npm run build:toss   # 또는 node scripts/make-dist.mjs — dist/ 준비
cp 등급분류/게임실행방법.txt dist/실행방법.txt
(cd dist && zip -r ../dist.zip .)
```

압축을 푼 폴더 최상단에 `index.html`이 바로 보여야 합니다.
(`dist/` 같은 폴더가 한 겹 더 생기지 않도록 `dist` 안에서 압축)

## 지난 반려 사유 대응

"게임이 실행되지 않는다"는 사유였으나, 확인 결과 게임 자체는 정상입니다.
압축 해제 후 `index.html`을 브라우저로 여는 것만으로 실행·플레이되는 것을
크롬으로 확인했습니다(데스크톱 1920×1080, 1366×768 및 `file://` 직접 열기).
따라서 실행 절차 안내가 빠진 것이 원인으로 보고, 위 세 문서 모두에 실행
방법을 명시하고 zip 안에도 안내 파일을 포함했습니다.
