# 게임물관리위원회 등급분류 신청 자료

| 파일 | 용도 |
|---|---|
| `게임물개요.txt` | 신청 화면의 **게임물 개요** 입력란(1000자 이내)에 붙여넣는 내용 — 현재 872자 |
| `게임물내용설명.txt` | 첨부하는 게임물내용설명서 |
| `게임실행방법.txt` | 심사관용 실행 안내. 첨부 파일로 올리고, 제출용 zip 안에도 `실행방법.txt`로 넣습니다 |

## 제출용 zip 만들기

심사관이 압축을 풀자마자 실행 안내를 보도록, 게임 파일과 같은 위치에
`실행방법.txt`를 넣어 압축합니다.

```bash
npm run build:toss   # 또는 node scripts/make-dist.mjs — dist/ 준비
cp 등급분류/게임실행방법.txt dist/실행방법.txt
(cd dist && zip -r ../dist.zip .)
```

압축을 푼 폴더 최상단에 `index.html`이 바로 보여야 합니다.
(`dist/` 같은 폴더가 한 겹 더 생기지 않도록 `dist` 안에서 압축)

## 지난 반려 사유 대응

"게임이 실행되지 않는다"는 사유였으나, 확인 결과 게임 자체는 정상입니다.
압축 해제 후 `index.html`을 브라우저로 여는 것만으로 실행·플레이되는 것을
크롬으로 확인했습니다(데스크톱 1920×1080, 1366×768 및 `file://` 직접 열기).
따라서 실행 절차 안내가 빠진 것이 원인으로 보고, 위 세 문서 모두에 실행
방법을 명시하고 zip 안에도 안내 파일을 포함했습니다.
