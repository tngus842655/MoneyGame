================================================================
              머니 게임 - 심사용 실행 방법 안내
================================================================

이 게임은 설치가 필요 없는 HTML5 게임입니다.
PC에서 웹브라우저만 있으면 바로 실행됩니다.


■ 실행 순서 (3단계)
----------------------------------------------------------------

  1단계.  첨부 파일 「dist.zip」을 바탕화면 등에 내려받습니다.

  2단계.  dist.zip 파일에 마우스 오른쪽 버튼을 클릭하고
          [압축 풀기] 또는 [모두 압축 해제]를 선택합니다.
          → 압축을 푼 폴더 안에 아래 항목이 들어 있습니다.

              index.html   ← 이 파일이 게임 실행 파일입니다
              js  폴더
              lib 폴더
              public 폴더

  3단계.  폴더 안의 「index.html」 파일을 마우스로 더블클릭합니다.
          → 웹브라우저가 열리면서 게임 시작 화면이 나타납니다.
          → 화면의 [▶️ 게임시작] 버튼을 클릭하면 게임이 시작됩니다.

  ※ 별도의 설치, 회원가입, 서버 실행이 필요 없습니다.
  ※ 권장 브라우저: 구글 크롬(Chrome) 또는 마이크로소프트 엣지(Edge)


■ 게임 조작 방법
----------------------------------------------------------------

  · 마우스를 게임 화면 위에서 좌우로 움직이면 떨어뜨릴 위치가 정해집니다.
  · 마우스 왼쪽 버튼을 클릭하면 그 위치로 돈이 떨어집니다.
  · 같은 금액의 돈끼리 닿으면 더 큰 금액으로 합쳐집니다.
  · 쌓인 돈이 화면 위쪽 빨간 점선에 2초 동안 닿아 있으면 게임이 끝납니다.


■ 실행이 되지 않을 때
----------------------------------------------------------------

  · index.html이 메모장이나 다른 프로그램으로 열리는 경우
    → index.html 파일에 오른쪽 버튼 클릭
    → [연결 프로그램] → [Chrome] 또는 [Microsoft Edge] 선택

  · 압축을 풀지 않고 zip 파일 안에서 index.html을 바로 실행하면
    게임 파일들을 찾지 못해 화면이 비어 보일 수 있습니다.
    반드시 압축을 먼저 풀어 주십시오.


■ 심사 시 참고 사항
----------------------------------------------------------------

  · 이 게임은 모바일 세로 화면 전용으로 제작되어, PC에서 실행하면
    화면 가운데에 세로로 긴 형태로 표시됩니다. 정상 동작입니다.

  · 배경음악은 PC에서 파일을 직접 열어 실행할 경우 브라우저의
    보안 정책상 소리가 나지 않을 수 있습니다. 효과음과 게임 진행은
    정상적으로 동작하며, 실제 스토어 배포본에서는 배경음악도
    정상 재생됩니다.

  · 광고(배너·보상형)는 실제 앱 환경에서만 노출됩니다. PC 실행 시에는
    광고 자리에 「AD · 배너 광고 영역」 안내와, 보상형 광고 대신
    3초짜리 테스트 화면이 표시된 뒤 해당 기능이 실행됩니다.

  · 유료 상품 「광고 제거」(3,850원, 1회 구매 영구 적용)는 토스 앱
    안에서만 판매되므로, PC로 실행하면 시작 화면에 구매 버튼이
    표시되지 않습니다. 이 상품은 광고를 보는 절차를 없애 줄 뿐이며,
    구매해도 통 흔들기·동전 제거(각 5회)와 부활(1회)의 사용 횟수는
    구매하지 않은 경우와 동일합니다. 결제 없이도 게임의 모든 내용을
    끝까지 확인하실 수 있습니다.

  · 앱인토스에서는 하루 1분 이상 플레이하면 토스포인트 5원이 지급되는
    플랫폼 이벤트가 진행 중입니다(하루 1회, 2026년 9월 30일까지).
    플레이 시간만 채우면 지급되는 확정 보상이며, 점수·순위와는
    무관합니다. PC 실행 시에는 표시되지 않습니다.

  · 랭킹 기능은 인터넷에 연결되어 있어야 실제 순위가 표시됩니다.
    연결되지 않은 환경에서는 예시 데이터로 화면만 표시되며,
    게임 진행에는 영향이 없습니다.
